# Portfolio Website

A personal portfolio website showcasing my journey as both a Software Engineer and Barista. This project is built with React, TypeScript, and Vite to create a modern, responsive web application.

## Features

- Modern, responsive design
- Interactive UI components
- Smooth animations and transitions
- Dark/Light mode support
- Project showcase section
- Blog/Articles section
- Contact form

## Website Sections

### Software Engineering
- **About Me**: Introduction and professional background
- **Skills & Technologies**: Technical expertise and tools
- **Projects**: Showcase of software development projects
  - Project cards with descriptions
  - Live demos and GitHub links
  - Technologies used
- **Experience**: Professional journey and achievements
- **Blog**: Technical articles and insights

### Barista Journey
- **Coffee Journey**: Introduction to my barista path
- **Coffee Blog**: Articles about coffee, brewing methods, and experiences
- **Gallery**: Photos of coffee art and brewing process
- **Coffee Projects**: Special coffee-related initiatives
- **Learning Progress**: Barista skills development

### Shared Sections
- **Home**: Landing page with featured content
- **Contact**: Get in touch form
- **Resume**: Downloadable CV
- **Social Links**: Professional and social media profiles

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/petchill/portfolio-v2.git
cd portfolio-v2
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser
